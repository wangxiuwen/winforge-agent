# 双机实测指引

两台 Windows 10/11（amd64）、同一局域网即可完成全部真机验证。

## 准备（每台机器）

1. 把 `dist/winforgedesk-windows-amd64.exe` 复制到对方机器任意目录
   （SHA256 见 `dist/SHA256SUMS-two.txt`）。
2. 双击运行：出现托盘图标 + 主窗口（若被折叠点"^"展开）。
3. 可选开机自启：`winforgedesk.exe autostart on`（登录后只留托盘）。

## 实测清单

| # | 项目 | 操作 | 预期 |
| --- | --- | --- | --- |
| 1 | 窗口基本操作 | 拖动标题栏、双击标题栏 | 窗口可拖动、双击最大化/还原（R61 修复后） |
| 2 | 自动发现 | 两机都运行后等几秒 | 双方设备列表都出现对方（在线） |
| 3 | 配对 | 一台点"+配对"→选对方→两台各点一次确认 | 配对成功弹窗，设备变为已配对在线 |
| 4 | 消息 | 传输 tab 选对方 → 输入 → 发送 | 对方聊天视图实时出现气泡 |
| 5 | 文件 | 发送文件/选择文件 → 对方点"接收" | 落地对方下载目录，可"打开" |
| 6 | 键鼠共享 | 共享 tab 给对方设"右→"方位 → 鼠标推过自己右边缘 | 进入控制对方（看到对方屏幕画面+光标红点） |
| 7 | 远程桌面 | 控制期间看控制 tab 的"对方屏幕（实时画面）" | ~3fps 画面，静止时停更（零带宽） |
| 8 | 交还 | 被控端把鼠标推向自己另一侧共享边 / 按 Esc | 控制结束，双方回空闲 |
| 9 | 热键 | Ctrl+Alt+D | 与推边等效的快捷切换 |
| 10 | 托盘 | 右键托盘图标 | 菜单：打开控制台/共享开关/退出 |

## 已知边界（非 bug）

- 断线重连收敛窗口（数秒到数十秒）内互发的消息不补投，稍后重发即可。
- "选择文件…"对话框若点击无反应请反馈（自动化环境偶现，人工未复现过）。
- 控制对端需要对方"键鼠共享"开关开启（窗口右上角勾选）。

## 问题反馈

日志在 `%APPDATA%\winforge\desk.log`（每实例独立），反馈时附上。
